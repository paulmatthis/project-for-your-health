Exercise log. Same model as food-log.md: you report what you did (text, voice, or a photo of the machine/settings), whoever is processing logs it, you never touch the file directly. See CLAUDE.md for the git pull/commit/push rule and image archiving.

How to process a new entry:
1. Identify the exercise, sets/reps, and weight (or assistance weight, for assisted machines - higher assistance weight means easier, since it counteracts body weight).
2. Archive any machine/equipment photo into images/, named YYYY-MM-DD-short-description.jpg.
3. Append a row per exercise to the table below (if the file gets unwieldy, summarize older weeks into a compact block and keep recent weeks in full detail, same convention as food-log.md).
4. Reply with a short status only, unless asked for more.

This is a rep/weight log, not a calorie log - profile-and-targets.md's activity level already accounts for exercise in the TDEE estimate, so sessions logged here are not separately added to or subtracted from the daily calorie budget.
